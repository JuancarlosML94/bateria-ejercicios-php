# Batería de Ejercicios PHP 

Repositorio con la resolución de los ejercicios prácticos de la Unidad de Trabajo 2 (PHP: Fundamentos).

## Estructura del Proyecto

El repositorio está organizado por partes según la actividad:

* **`parte1/`**: Estructuras básicas y salida por pantalla.
* **`parte2/`**: Manejo de variables y tipos de datos.
* **`parte3/`**: Formularios básicos con método GET.
* **`parte4/`** ("Cuñado 2"): Generador de frases aleatorias combinando arrays y campos personalizados enviados por formulario.
* **`parte5/`** ("Comparator"): Calculadora y comparador lógico/aritmético utilizando formularios GET y estructuras condicionales `if-else if-else`.
* **`parte6/`** ("Strings cachondas"): Manipulación avanzada de cadenas y arrays usando las funciones `explode()` y `implode()`, junto con bucles tradicionales.

## Entorno de Ejecución
* **Servidor local:** XAMPP (Apache / PHP)
* **Control de versiones:** Git y GitHub
